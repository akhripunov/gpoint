# Creator seller flow

Each creator owns a seller bot and its associated Main Mini App. The shared GPoint Seller App can serve creator context by route/configuration, but the Telegram ownership and payment identity remain per creator bot. The creator receives Stars for the VIP digital product; GPoint receives only Telegram's official affiliate commission through a GPoint-owned bot peer.

This is `PARTIAL` feasibility, not a blanket white-label claim: the same hosted frontend/backend is reusable, but a single GPoint bot cannot make every creator's sale appear to belong to that creator's bot or affiliate program.
